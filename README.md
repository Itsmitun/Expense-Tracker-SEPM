A web-based application that helps users efficiently manage their personal finances by tracking daily expenses, categorizing spending, visualizing data, and gaining insights into financial habits. Built with HTML, CSS, and JavaScript for a clean and responsive user interface.

🚀 Features
User sign-up and login system

Dashboard with a summary of total expenses

Add, edit, and delete expenses with category, amount (₹), and date

Import expenses from CSV files

Interactive data visualizations (bar chart and pie chart)

Custom expense categories

Recurring expenses for regular payments

Budget alerts and notifications

Clean, responsive, and user-friendly UI

📊 Visualizations
Bar Chart: Displays spending per category

Pie Chart: Shows percentage breakdown of expense categories

Monthly Summary: Total expenses and most frequent category

🎯 Project Goals
Promote responsible financial behavior through visual insights

Simplify expense tracking with automation and CSV import

Provide a personalized, interactive user experience

📦 Technologies Used
HTML5

CSS3

JavaScript (Vanilla)

Chart.js for data visualizations
